## ⚠️ CRITICAL WARNING

This agent **executes arbitrary Windows commands** with full user permissions. it is though prevented from executing "del", "rmdir", "rd", "erase" and "format"

**DO NOT USE IF:**
- You don't understand what commands it will execute
- You value your system files
- You're running it on a production machine
- You don't have backups

**Risks:**
- Can delete your entire drive
- Can steal credentials and data
- Can install malware
- Can corrupt Windows

Use at your own risk in isolated environments only.
